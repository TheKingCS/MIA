# Visual Identity

The comic uses MIA's real design language: the same one as her screens
(`web/tokens.css`, `docs/design/STARK_INTERFACE.md`).

**The idea:** an inventor's own operating system. Real technology built in a
private workshop: precise, quiet, expensive. It's not cyberpunk and not a movie
prop. Published art borrows from no existing franchise.

**Palette:**

| Token | Colour | Means |
|---|---|---|
| accent | `#35d4ff` electric cyan | MIA, her voice, anything active |
| bg / panels | near-black graphite, layered | depth by layers, not borders |
| win | `#f6c453` gold | earned celebration only |
| attention | `#f2b33d` amber | needs attention; Sentinel's edges |
| ok | `#4fc48c` green | healthy, done; Tandem |
| silver, white | | text, lines, highlights |

**MIA:**
- a glowing cyan orb with concentric rings;
- holographic panels with fine lines and 6 px corners;
- glow only on her and what's active.

**Panels:**
- clean, cinematic framing;
- dark backgrounds that let the light read;
- interface overlays drawn as real interfaces;
- lettering in a clean sans.

**Reference sheets** (made once and approved, then attached to every panel's
prompt): MIA's orb in each state, each council member, the workshop and the
glasses' view. They're listed here by hash once made (`data/saga/art/`,
DEC-0086).

**Art route:** a local image model on MIA's own computer, if it can be made to
work on its AMD card (DEC-0086, T-0036). Until then, MIA prepares a prompt per
panel, built from this file and the character files, never written freehand.
