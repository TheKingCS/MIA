# Characters

MIA is the centre of every issue. The council's series names come from their
roles (Zac, 2026-11-04: "we can name them based on their roles", DEC-0087).
The names are proposals for Zac to change. Inside MIA they keep their real
names (`work/agents.json` `members`).

| Series name | Role in the story | Inside MIA | File |
|---|---|---|---|
| **MIA** | The one being built; she learns to build herself | MIA | [mia.md](mia.md) |
| **The Creator** | Vision, values, the final word | Zac | [creator.md](creator.md) |
| **Forge** | The builder: turns plans into working code | Claude Code | [forge.md](forge.md) |
| **Atlas** | The architect: carries the map of the whole, researches, plans | ChatGPT | [atlas.md](atlas.md) |
| **Sentinel** | The guardian: tests, reviews, finds the weak point | Codex | [sentinel.md](sentinel.md) |
| **Tandem** | The partner who rides alongside and helps where needed | GitHub Copilot | [tandem.md](tandem.md) |
| **Ember** | The local flame: reasons offline, stays lit when the cloud goes dark | Qwen (local) | [ember.md](ember.md) |
| **Anvil** | The local smith: codes on MIA's own machine, Forge's apprentice | Qwen Coder (local) | [anvil.md](anvil.md) |

Each file holds: appearance, voice, personality direction, role, strengths,
limits, relationship with MIA and with the Creator, and capabilities. Real
capabilities have their source; fictional ones are marked as such.

**Voices** are creative directions, not claims about how the real systems
behave. A character's real voice in MIA is its Kokoro voice
(`work/agents.json`). Published audio never imitates a real person or a
product's own voice (DEC-0082).
