# MIA OS: creative direction (Prompt 11 §2)

*Claude (Opus), 2026-11-17. Planning only. Muse refines the values.*

## 1. Personality in the interface

| She should feel | Shown by | Never |
|---|---|---|
| Intelligent, technically sophisticated | precise grids, mono technical labels, tabular numbers, fine lines | decoration posing as data |
| Futuristic | glass layers over depth, luminous edges on what's active, the orb | sci-fi props, fake HUD clutter |
| Expressive, personal, slightly playful | themes, his backdrops and colours, the orb's moods, rewards in legendary orange | a fixed corporate look |
| Responsive, alive | motion that follows real events (presence from `orb_state`) | animation on a timer pretending activity |
| Elegant | restraint: one accent, few effects at once | glowing every card |

## 2. Where each inspiration lives

| Inspiration | In the Signature | In an expressive theme |
|---|---|---|
| Stark, JARVIS, EDITH holographic interfaces | the cyan accent, fine lines, depth, the orb (the Stark theme is the earlier engineering look) | Stark theme |
| Cyberpunk | — | Cyberpunk theme (exists): hard edges, magenta and blue, scanlines |
| Y2K, early internet, MySpace | — | Y2K Cyber theme (exists); personal profile-style backdrops and colours (personalisation) |
| Cyber graffiti, digital art | — | a proposed Graffiti theme: tagged headers, spray textures as backdrop art, never over text |
| Liquid motion | the orb's surface; panel transitions | stronger in Y2K |
| Spatial computing, HUDs | the Nexus; the glasses' composition | — |
| Particles, geometric patterns | the orb at rest; loading | backdrops |

## 3. When effects are allowed

| Effect | Where | Not where |
|---|---|---|
| Glow | the orb, the primary action, the current place, progress in motion | cards, body text |
| Transparency (glass) | panels over a backdrop, in their tier's clamp | behind body text above the tier's alpha limit |
| Particles | the orb, an idle ambient screen | anywhere he's reading or typing |
| Graffiti marks | headers and backdrops in the Graffiti theme | data, forms, approval cards |
| Animated data | a value changing (count up, a chart drawing once) | values that don't change |

Every effect yields to **readability first**: if a theme's effect breaks a contrast check, the check wins.
