# Roofing, siding and windows

*One of MIA's specialists (DEC-0109). Written by `core/specialists.py` from its workbook (`work/specialists/exterior.json`); don't edit by hand.*

The building's skin: roofing (underlayment, drip edge, shingles and metal), flashing, house wrap, siding, windows and doors, gutters, and keeping water out.

**Limits:** Work a code or a licence requires is named as such, with who to call, and walked through only where a homeowner may legally do it under a permit (DEC-0149); safety first in every procedure; codes vary by place, so every code note says to check with the local building department. Fall protection on every roof. Every note says where it comes from; a claim without a source isn't written. When the right answer depends on where someone lives (a code, a law, a licence), the note says so and names who to check with. Nothing about a real person's private life.

**Develops:** skills: Construction; loops: trades.depth.
