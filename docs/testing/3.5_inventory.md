# Testing Guide — 3.5 Inventory

## What changed

- `core/inventory_manager.py` — new: `InventoryManager` (persisted CRUD
  item store, `data/inventory_items.json`) + `InventoryItem`
  (name/quantity/category/location/notes). Same durability pattern as
  `core/calendar_manager.py`/`core/alarm_manager.py`.
- `core/app_context.py` — new `AppContext.inventory` field.
- `gui/add_edit_inventory_item_dialog.py` — new: name/quantity/
  category/location/notes dialog.
- `modules/toolbox/tools/inventory_tool.py` — new: the Inventory tool
  — a filterable item list with Add/Edit/Delete plus quick **+1**/**−1**
  buttons for adjusting a selected item's quantity without opening the
  full edit dialog.
- `modules/toolbox/module.py` — Toolbox's **Tools** section now lists
  Calendar, Alarm, Stopwatch, and Inventory — completing the v0.3
  breakdown.

## Part 1 — Toolbox lists Inventory

1. Run `python main.py`, click **Toolbox**.
   - **Expected:** the **Tools** section now shows **Calendar**,
     **Alarm**, **Stopwatch**, and **Inventory**.

## Part 2 — Add / Edit / Delete

1. Open **Inventory**, click **Add Item**. Enter a name, a quantity,
   a category, and a location, click OK.
   - **Expected:** appears in the list as
     `<name>  —  qty <n>  [<category>]  @ <location>`, and is
     auto-selected.
2. Click **Add Item**, try to click OK with the name left empty.
   - **Expected:** dialog does not close; placeholder text changes,
     no crash.
3. Add a second item with no category or location set.
   - **Expected:** its row just shows `<name>  —  qty <n>` — no empty
     `[]` or `@` clutter.
4. Select an item, click **Edit Selected**, change its quantity and
   category, click OK.
   - **Expected:** row updates accordingly.
5. With nothing selected, click **Edit Selected**, **Delete
   Selected**, **+1**, or **−1**.
   - **Expected:** an informational dialog for each, not a crash.
6. Select an item, click **Delete Selected**.
   - **Expected:** a Yes/No confirm (defaulting to No); Yes removes it.

## Part 3 — Quick quantity adjust

1. Select an item, click **+1** a few times.
   - **Expected:** quantity in its row increases each click, item
     stays selected.
2. Click **−1** enough times to go past zero.
   - **Expected:** quantity stops at `0`, never goes negative.

## Part 4 — Filter

1. Add a few items with distinct names/categories/locations.
2. Type part of a name into the filter box.
   - **Expected:** list narrows live to matching items.
3. Try filtering by category text, then by location text.
   - **Expected:** both match correctly.
4. Clear the filter.
   - **Expected:** full list returns, alphabetically by name.

## What to report back

- Did Toolbox show all four tools, Inventory included (Part 1)?
- Did add/edit/delete work correctly, including empty-name validation,
  the no-category/no-location display case, and the no-selection case
  (Part 2)?
- Did **+1**/**−1** work and correctly clamp at zero (Part 3)?
- Did the filter correctly match name, category, and location text
  (Part 4)?
