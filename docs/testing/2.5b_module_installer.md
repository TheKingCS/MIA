## Part 1 — Install a valid module from a folder

1. Create a minimal valid test module folder somewhere *outside* the project (simulating a USB drive):
   ```bash
   mkdir -p ~/test_modules/weather_test
   touch ~/test_modules/weather_test/__init__.py
   cat > ~/test_modules/weather_test/module.py << 'EOF'
   from __future__ import annotations
   from gui.widgets.placeholder_widget import build_placeholder_widget
   from modules.module_base import ModuleBase

   class WeatherTestModule(ModuleBase):
       module_id = "weather_test"
       display_name = "Weather Test"
       description = "A test module installed via the Add Module feature."
       icon = "\u2600"

       def get_widget(self):
           return build_placeholder_widget(self.display_name, self.description, self.icon)
   EOF
   ```
2. In the running app, go to **Modules**, click **📁 Add Module (Folder)**.
3. In the file picker, navigate to and select `~/test_modules/weather_test`.
   - **Expected:** a dialog appears: "Installed 'Weather Test' successfully."
4. Go to the main menu.
   - **Expected:** "Weather Test" now appears in the grid — no restart needed.

## Part 2 — Confirm a bad module is rejected with a clear reason

1. Create an intentionally broken module (missing `get_widget`):
   ```bash
   mkdir -p ~/test_modules/broken_test
   touch ~/test_modules/broken_test/__init__.py
   cat > ~/test_modules/broken_test/module.py << 'EOF'
   from modules.module_base import ModuleBase

   class BrokenTestModule(ModuleBase):
       module_id = "broken_test"
       display_name = "Broken Test"
   EOF
   ```
2. In **Modules**, click **📁 Add Module (Folder)**, select `~/test_modules/broken_test`.
   - **Expected:** an "Install Failed" dialog appears with a specific error (something like "Could not instantiate the module class...").
3. Confirm nothing was actually installed:
   ```bash
   ls ~/Projects/MIA/modules/ | grep broken_test
   ```
   Should print nothing.

## Part 3 — Install from a .zip

1. Zip up the working test module from Part 1 (reusing it under a new name so it doesn't collide):
   ```bash
   cp -r ~/test_modules/weather_test ~/test_modules/weather_test2
   sed -i 's/weather_test/weather_test2/g; s/WeatherTestModule/WeatherTest2Module/' ~/test_modules/weather_test2/module.py
   cd ~/test_modules
   zip -r weather_test2.zip weather_test2
   ```
2. In **Modules**, click **🗜 Add Module (.zip)**, select `weather_test2.zip`.
   - **Expected:** "Installed 'Weather Test' successfully" (or similar, matching whatever display_name is inside), and it appears in the main menu.

## Part 4 — Duplicate module_id is rejected

1. Try installing the **same** `weather_test` folder from Part 1 again (Add Module Folder, same path).
   - **Expected:** "Install Failed" — error should mention the module_id is already used by another installed module.

## Cleanup

```bash
cd ~/Projects/MIA
rm -rf modules/weather_test modules/weather_test2 modules/broken_test
rm -rf ~/test_modules
```
Restart the app afterward — remember, `rescan()` only detects *additions*, so removed folders won't disappear from the menu until a full restart.

## What to report back

- Did the valid module in Part 1 install and appear in the menu without a restart?
- Did the broken module in Part 2 get rejected with a clear, specific error message (not a crash)?
- Did the `.zip` install in Part 3 work?
- Was the duplicate install in Part 4 correctly refused?
