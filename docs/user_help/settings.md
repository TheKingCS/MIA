# Settings, Modules, and Profiles

## Appearance and device profile

Settings is where you change the visual theme (Dark Field, Low Energy,
Colored, Anime Monochrome) and view/change which edition — Core
(Pi 5 + AI HAT) or Home (desktop) — this install is running as.
Switching themes takes effect immediately, no restart needed.

## Managing modules

The Modules screen (in Apps) lists every installed module, lets you
enable or disable each one (a disabled module disappears from Apps
immediately, no restart needed), rescan for newly added module
folders, and install a new module from a folder or .zip file.

## User profiles

Multiple people can have their own profile on the same device. "Switch
User" in the header bar opens the profile picker; password-protected
profiles will prompt for their password there.
