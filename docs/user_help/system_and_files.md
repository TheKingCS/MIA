# Dashboard, Diagnostics, Files, Modules, and The Lab

## Dashboard

Dashboard is your at-a-glance home view — recent activity, your active
Mission's progress, recent Memories, and upcoming items, all in one
place without opening each module separately. Click any card to jump
straight into that module.

## Diagnostics

Diagnostics shows real system health, logs, and hardware status —
things like storage space, temperature, and recent errors. Click
Refresh to pull the latest readings.

## Files

Files lets you browse and manage the actual files on this device — Up
and Home navigate the folder tree, New Folder creates one, Rename and
Delete manage whatever's selected.

## Modules

The Modules screen (internally "module_browser") is where you manage
MIA's own feature modules — enable or disable one, Rescan to pick up
anything newly added to the modules folder, or install a new one from
a folder or a .zip file.

## The Lab

The Lab is for sensor testing, experiments, and calibration — Add
Reading logs a new data point, Delete Selected Reading removes one,
and readings are graphed over time so you can watch a trend as it
develops.
