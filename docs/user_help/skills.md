# Skills: your real skill tree

## What a Skill is

Skills is a categorized grid of skill cards sitting underneath your
overall profile Level — instead of one flat XP bar, real activity
across the app (Missions, Workouts, Kitchen, Maintenance, Budget)
grants XP toward specific skills, so your progress actually reflects
what you've been doing. Each card shows its icon, name, level, and an
XP progress bar. Category tabs group related skills; if you answered the interview
questions when your profile was created, those categories are starred
and sorted first. MIA also keeps an eye on this: if you said you're
interested in a category but still have zero real XP there a few
weeks later, or a category you genuinely used to work in has gone
quiet for 60+ days, either one shows up as a real Observation, not
just silently ignored.

## Capability status: Locked, Learning, Practiced, Demonstrated

Every skill also carries a capability status — Locked (not started),
Learning, Practiced, or Demonstrated — shown in the legend and on each
card. Locked is display-only: it doesn't block anything, and XP still
lands on a Locked skill exactly the same as any other. A locked skill
shows dimmed with a lock badge naming what prerequisite unlocks it.

## The skill tree

Real prerequisite connections are drawn as lines behind the card grid,
so you can see which skills build on which — a genuine tree, not just
a grid with a category label.

## Manage which skills a Mission grants

Open a Mission and use "Manage Skills…" to pick which skills it grants
XP toward — you can set this up front when creating a goal, or add it
retroactively to a Mission you already completed, and the XP lands
immediately either way.

## Achievements and your next honest step

The right-hand column shows your most recent skill achievements, and
a "Next Honest Step" card naming one real, concrete skill to focus on
next — a plain rule-based pick from your own current progress, not a
guess.
