# Music: local library, playlists, and playback

## Building your library

On the Library tab, click Scan Library to index your music folder —
this reads real tags (title, artist, album) from your files and skips
anything already indexed and unchanged, so re-scanning after adding a
few new songs is fast. Select a track and click Play, or Add to
Playlist… to file it into one.

## Playlists

The Playlists tab's New Playlist… creates one; select it and Play
Playlist starts it from the top. Remove Track takes a song back out
without deleting the file itself; Delete Playlist removes the playlist
(again, never the underlying music files).

## The transport bar

Playback controls (previous/play-pause/stop/next) stay visible at the
bottom no matter which module you're in or which tab you're on — you
can keep browsing Recipes or checking your Budget with music still
playing.
