# Memories: trip recaps, stats, and photos

## What Memories shows you

Memories is a read-only recap of your Expeditions, most recent first —
duration, distance and pace per activity type, which waypoint
categories you visited, and a strip of photo thumbnails from that
trip. An "On This Day" section appears at the top when today's date
matches a past Expedition's start date in an earlier year.

## Viewing a route

Each Trip inside a recap has its own View Route Map button, which
opens the same map view you'd see from the Navigation module, showing
exactly where that trip went.

## Adding to your Memories

Memories itself has nothing to add or edit — it's purely a recap of
Expeditions, Trips, Waypoints, and Journal entries you've already
created elsewhere (the Expeditions, Navigation, and Notes modules).
Log a real trip there and it shows up here automatically.
