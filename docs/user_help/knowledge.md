# Knowledge: Offline Reference Library

## What it is

The Knowledge module holds installed offline reference packs —
encyclopedia articles, repair/how-to guides, field medicine references,
and similar content — all searchable without an internet connection.

## Installing and managing packs

Install a pack file to add it to your library, search across every
installed pack at once, and delete a pack you no longer need to free up
space. Each pack shows up as its own searchable source.

## Getting answers through the Assistant

You don't have to open Knowledge and search manually — ask the
Assistant a question directly (like "what are the symptoms of
hypothermia?") and it will pull relevant passages from your installed
packs into its answer automatically. If nothing in your library covers
the topic, it will say so rather than guess.
