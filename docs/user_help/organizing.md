# Notes, Toolbox, and Staying Organized

## Notes

The Notes module holds dated, searchable, taggable journal entries —
general-purpose notes, not tied to a specific Trip (for trip-specific
journal entries, see the Expeditions help section instead). Tag entries
to find them again later, or just search by keyword.

## Toolbox

Toolbox is a collection of everyday tools, each its own tab:

- **Alarms** — set a one-time or recurring alarm with a label.
- **Calendar** — add, list, and remove dated events.
- **Inventory** — track quantities of general items (not electronics
  components — those live in Workshop & Electronics). Add items, list
  or search them, adjust a quantity up or down, or remove one entirely.
- **Project Manager** — Projects (Planning/Active/On Hold/Complete)
  hold Tasks. Add a Project, add Tasks under it, mark Tasks done, and
  delete either when you're finished with them.
- **Stopwatch** — a simple timer for quick use.
- **Calculators** — unit conversion (length, area, volume, weight,
  temperature) and other quick calculators.

## Workshop & Electronics

A separate module with its own help section — an electronics
components inventory plus a small Materials/Jobs/Products/Ledger
production pipeline. See the Workshop help section for details.
