Committing a WAITING_ON note that named Zac's truck was stopped by the safety check, rightly: the repo is never the place for a vehicle's name, an address or a lender. Write 'seven assets', 'three properties'; the specifics live in the gitignored data/_import/ pack and his profile. Commit messages that describe mailbox-reading code in detail were held back the same way.
