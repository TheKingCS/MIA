Make the test suite give the same result on every machine.

On this PC, unchanged code fails these tests, because of what's installed here, not because the code is wrong:
- tests/test_ocr.py::test_unavailable_without_tesseract: it expects Tesseract to be missing, and it's installed here.
- tests/test_inbox.py (6 tests, e.g. test_a_manual_pdf_is_matched_to_the_mower, test_email_with_a_pdf_attachment,
  test_filing_a_manual_attaches_it_and_adds_the_ticked_tasks, test_tools, test_inbox_screen): reading PDFs and OCR behave
  differently with Tesseract present.
- tests/test_textbook_tutor.py (7 tests): "ValueError: The PDF has no text", PDF reading on this machine.

Run each failing test, find the actual cause, and make the tests control what they depend on (monkeypatch the
Tesseract check, build the PDF the test needs, and so on) so they pass whether or not Tesseract is installed.
Rules: never skip, disable, xfail or delete a test to get green, and don't weaken what a test checks. Change product
code only if a test shows a real bug in it, and say so. Leave tests/test_plaid_manager.py and
tests/test_your_data_and_undo.py alone (the first is work in progress; the second fails only in a full run).
