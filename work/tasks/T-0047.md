Drafted at Night School by MIA's teacher (core/loop_coverage.py, DEC-0101). Build each loop in core/loops.py with its `covers`; check each measure reads records MIA really keeps.

- **actions.failed** (flow:actions): approved actions that failed when they ran, as a share of approved ones (7 days). Measure: core/actions.py ActionCenter (context.actions): read _proposals.values() where profile_id == person_id(context) and decided_at >= _since(7); value = count(status == FAILED) / count(status in (EXECUTED, FAILED)), n = that denominator. ActionCenter.approve() sets FAILED and decided_at. The proposals live in memory only, so a restart clears them; the reading covers time since boot (at most 7 days).. Better lower, floor 0.05, scope person.

- **actions.mia_declined** (flow:actions): actions MIA proposed that the person turned down or let expire, as a share of her proposals that were settled. Measure: Same source: proposals with proposed_by == 'mia', profile_id == person and created_at >= _since(7); value = count(status in (REJECTED, EXPIRED)) / count(status in (EXECUTED, FAILED, REJECTED, EXPIRED)). Status changes come from ActionCenter.reject() and _expire(). Undo is already watched by answers.undo_soon (failure_log 'undo_soon'), so it isn't counted again here.. Better lower, floor 0.5, scope person.

- **email.discarded** (flow:email): drafts thrown away instead of sent, as a share of drafts that were settled (30 days). Measure: core/email_drafts.py EmailDrafts (context.email_drafts, the person's own email_drafts.json): drafts in _drafts with created_at >= _since(30) and status in (SENT, DISCARDED); value = count(DISCARDED) / that count. DISCARDED is set by gui/email_draft_dialog.py and server/app.py; SENT by mail_send.send_draft(). Only the last 50 drafts are kept (_KEEP), which is enough for 30 days. Missing: a failed send (SendError) isn't recorded anywhere, so failed sends can't be counted. Recording one in failure_log would add that number.. Better lower, floor 0.4, scope person.

- **email.left_open** (flow:email): drafts neither sent nor discarded after 7 days. Measure: Same store: count of open_drafts() whose created_at < _since(7); n = len(open_drafts()).. Better lower, floor None, scope person.

- **gate.dismissed** (flow:gate): unprompted messages that went out and were dismissed, as a share of those that went out (7 days). Measure: core/communication_gate.py CommunicationGate (context.communication, the person's communication_log.json): entries in _log with action == ACT and at >= _since(7); value = count(entry has dismissed_at) / that count. dismissed_at is set by _on_notification_dismissed(). Entries with urgency == URGENT are left out because they always go out.. Better lower, floor 0.5, scope person.

- **gate.expired** (flow:gate): messages held back for later that expired before they could go out, as a share of those held back. Measure: Same log, 7 days: value = count(action == DROP and reason starts with 'waited too long') / count(action == DEFER). The first are written by _take_due_pending(), the second by offer_batch().. Better lower, floor None, scope person.

- **phone.sync_stale** (flow:phone): hours since the last good sync with the home computer. Measure: core/sync.py status(context) on the linked device, read from SyncState status.json: 'last' is set by sync_now() and 'problem' by SyncLoop._run() on HomeLinkError/OSError. value = hours from 'last' until now, n = 1, and the detail adds 'problem' if one is set. Returns None when status()['linked'] is False.. Better lower, floor 24, scope device.
